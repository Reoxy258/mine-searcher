# 寻路扫雷

先探出一条安全道路，再看人物跑向终点。支持电脑和手机的 H5 扫雷解谜小游戏。

[在线试玩](https://reoxy258.github.io/mine-searcher/) · [验证记录](docs/QA.md)

![安全道路连通后，人物开始跑步](docs/running.jpg)

## 规则

**每关保证至少有一条从左下 S 到右上 E 的可行道路，并通过数字推理验证，无需猜雷。**

1. 点击任意未插旗的未知格探雷，人物始终留在 S，不随点击移动。
2. 数字表示周围八格（含斜角）的雷数；零区域自动展开。起点周围与终点保证安全。
3. 已打开的安全格按上下左右连通 S 与 E 后，人物才沿完整安全路线跑到 E，动画结束后结算。斜角与插旗格不能通行，仅打开终点不算连通。
4. 不必清空整个地图或标出所有雷，只需探通一条路。

## 降低难度

- **更宽松的前 10 关**：降低雷数，起点 3×3 保证安全；前 5 关至少自动打开 28 格，第 6～10 关至少打开 24 格。地图不会开局就直通终点。
- **默认轻松模式**：每关 1 次触雷保护。第一次误点雷格自动插旗并继续，人物仍在 S；保护用尽后再触雷才结束。标准模式无保护，触雷即结束。
- **免费线索**：根据可见数字给出确定安全 / 有雷格，或提醒撤销安全格上的误旗。使用多少次都不扣星，也不自动翻格。
- **自由探索**：可先打开任何位置，包括保证安全的 E，利用附近数字反向推理。
- **无时间压力**：用时和探雷次数都不扣星。未触发保护得 3 星，使用过保护得 2 星，保留最高纪录。

点击模式按钮可在轻松 / 标准之间切换。确认后重开当前关，已获得星级保留。自动标记的雷也可撤旗，但撤旗后仍有雷。

## 操作

| 功能 | 操作 |
| --- | --- |
| 探雷 | 探雷模式下点击未知格 |
| 插旗 / 撤旗 | 切换插旗模式后点击；电脑也可直接右键 |
| 键盘选格 | 方向键 / WASD，不移动人物 |
| 执行当前模式 | Enter / 空格 |
| 切换模式 | F；G 返回探雷 |
| 暂停 | P / Esc / 暂停按钮，同时冻结跑步动画 |
| 大地图 | 在地图内部横向滑动；跑步时容器跟随人物 |

跑步期间锁定探雷和插旗，仍可暂停、重试或切换关卡。重试、切关、确认切换难度会取消旧动画。跑步中刷新会从 S 重新播放，抵达前不会提前记录通关。

共 6 组 / 30 关，固定种子，重试同图。进度保存在当前浏览器；旧版星级自动保留，当前关按新规则重新开始。存储被拒绝时仍可游玩，界面会说明无法保存。音效默认关闭。

## 开发与发布

Node.js 22+，无需安装依赖。

```sh
npm run dev
npm test
npm run build
```

默认预览 `http://127.0.0.1:4180`。构建生成静态站点 `dist/` 和可双击离线游玩的 `dist/standalone.html`。GitHub Pages 使用仓库子路径，推送 main 后先测试、构建再发布。

| 文件 | 职责 |
| --- | --- |
| src/engine.js | 数字、推理、探雷、连通检测、护盾、存档 |
| src/levels.js | 30 关参数与种子 |
| src/app.js | 输入、连续跑步动画、暂停、结果与界面 |
| src/styles.css | 响应式界面与跑步视觉 |
| tests/engine.test.js | 规则 agent 的独立验证 |
| tests/ui.test.js | 界面 agent 的独立验证 |

主 agent 制作与修复，两个子 agent 分别负责规则与界面验证。
