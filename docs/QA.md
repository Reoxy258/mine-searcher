## 自动验证

`npm test`：**18 / 18 通过**。

- 30 关全部通过可见线索推理通关检查；对每个推出的安全格 / 雷格另用实际雷位核实正确性。
- 每条行走路径逐步核对四向相邻；未探索格不能作为自动寻路的中间节点。
- 八邻域雷数、边角、零区域展开、斜对角不能跨越、旗帜上限与阻挡。
- 错误旗帜不当作事实，提示只使用已显示数字；确定安全的误旗会提示撤销。
- 展开终点不会自动获胜；走过终点时及时停止；胜负后不能继续操作。
- playing / won / lost 三种状态的完整保存恢复；损坏存档及存储拒绝时的降级行为。
- HTML 标识唯一、控制器静态目标完整、四个弹窗均有对应的无障碍名称。

`npm run build`：通过，生成静态站点及零外部依赖的 `standalone.html`。

## 浏览器实际操作

- 第一关通过真实「线索」按钮与格子点击安全抵达，45 步，12 次提示，1 星；结算后进入第二关。
- 玩法说明、关卡选择、暂停 / 继续、重试均可打开和关闭，暂停时计时不增加。
- 关卡选择可直接进入第 30 关；在边界格踩雷后结束、揭示雷位；刷新完整恢复失败状态，重试重新开始。
- F 切换插旗，方向键选格，Enter 插旗 / 撤销，F 返回；选格不增加行走步数。
- 修复后核对移动后唯一的 `tabindex=0` 格与玩家位置一致。
- 320px 小屏页面没有横向溢出；11×14 地图在自身容器中横滑，实测格宽约 33px。
- 静态单文件在浏览器启动成功：56 个首关格子，0 个外部脚本，0 个外部样式，控制台无错误。

## 审查问题与修复

- 行走后 Tab 入口仍留在旧格：移动后同步唯一键盘入口。
- 关卡、重试、暂停弹窗缺少无障碍名称：为 h2 添加 id 并关联 aria-labelledby。
- 手机后期地图格子缩到约 20px：地图设置最小宽度 410px，仅地图内横滑。
- 小尺寸数字颜色偏浅：加深 1、2、3、4～8 的文字颜色，保持颜色区分。
- 提示落在手机屏幕外：高亮目标自动滚入地图视野。
- 失败存档恢复时误拒绝踩雷位置：允许失败状态停在未揭示的雷格。

## 范围与限制

30 关采用固定种子，重试保持同图；当前不含随机无限模式。推理机器人验证逻辑可解，浏览器验证关键交互，两者不能代替所有关卡的真人难度测试。未验证 iOS / Android 真机浏览器差异；当前手机结果来自窄视口测试。
